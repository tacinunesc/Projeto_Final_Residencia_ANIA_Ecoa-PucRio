## 📌 Visão Geral do Projeto

Este repositório consolida o **Projeto Final** desenvolvido na **Residência em Análise de Dados com Inteligência Artificial da ECOA / PUC-Rio**. 

O objetivo principal desta entrega foi desenvolver uma solução analítica e orientada por Inteligência Artificial para apoiar os objetivos estratégicos da nossa stakeholder, **Débora**, Gerente de Programas de Inovação Tecnológica. O projeto abrange desde a estruturação de dados até a entrega de visualizações dinâmicas e uma apresentação executiva interativa de impacto.
